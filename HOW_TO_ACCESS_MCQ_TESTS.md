# 📚 How to Access MCQ Tests - User Guide

## ✅ **MCQ Test Module is Now Live!**

Users can now take tests from all generated MCQ banks. Here's how to access it:

---

## 🎯 **3 Ways to Access MCQ Tests**

### **Method 1: From Dashboard (EASIEST)**
1. Login to your account
2. Go to **Dashboard** (`/dashboard`)
3. Look for the **"MCQ Tests"** card (blue card with ✅ icon)
4. Click on it
5. You'll see all available MCQ banks to test from!

### **Method 2: Direct URL**
Simply navigate to: **`/mcq-tests`**

### **Method 3: From MCQ Bank Page**
1. Go to **MCQ Bank** page
2. Each MCQ bank will have a "Take Test" button (coming soon)

---

## 📖 **How It Works**

### **Step 1: Browse Available Tests**
On the `/mcq-tests` page, you'll see:
- All generated MCQ banks
- Number of questions in each bank
- Difficulty distribution (Easy/Medium/Hard)
- Your previous attempts and best scores
- Department categorization

### **Step 2: Start a Test**
1. Click **"Start Test"** on any MCQ bank
2. Test begins immediately with a timer
3. Answer questions at your own pace
4. Navigate between questions using the number grid
5. Submit when ready

### **Step 3: View Results**
After submission, you'll see:
- Your score (percentage)
- Grade (A+, A, B+, B, C, D, or F)
- Pass/Fail status (70% is passing)
- Correct vs Incorrect breakdown
- Time taken
- Difficulty-wise performance

### **Step 4: Review Answers**
- See all questions with your answers
- Correct answers highlighted in green
- Wrong answers highlighted in red
- Detailed explanations for each question
- SOP references for learning

### **Step 5: Retake (Optional)**
- Click "Retake Test" to improve your score
- All attempts are tracked
- Best score is displayed
